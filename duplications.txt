--------------------------------------------------------------------------------
1. 19 Separate setup.py Scripts:
   Each module directory contains an isolated setup.py script with identical
   CUDAExtension compilation arguments and include paths pointing back to root
   src/, include/, and kernels/ directories:
   - ChannelNorm/setup.py
   - correlation/setup.py
   - vid_2_vid_correlation/setup.py
   - alt_cuda_corr/setup.py
   - DCNv2_latest/setup.py

   - SeparableConvFlow/setup.py
   - lietorch/setup.py
   - ops_smm/setup.py

2. Monolithic CMakeLists.txt Target Duplications and Copy-Paste Errors:
   - CMakeLists.txt builds 31 separate shared libraries.
   - DCNv2_latest (lines 80-82) mistakenly compiles kernels/correlation_kernel.cu
     and src/correlation.cpp (RAFT correlation) as part of DCNv2.
   - HASH_QUERY_SRC (lines 129-134) references
     'hash_query/kernel/convolution_gather_scatter_cuda.cu' which does not exist
     (the directory actually contains hash_cuda.cu).
   - An empty coordinate_hashing/ directory exists at the root because
     CMakeLists.txt looked for ${CMAKE_CURRENT_SOURCE_DIR}/coordinate_hashing
     instead of sparse_conv_operations/coordinate_hashing.
